# 盔甲附加 (Armor Addon) 1.3.2

Minecraft **1.21.1** / **NeoForge** 模组。

## [1.3.2]

### 新增

- **超重型甲的胸甲图标重新绘制。** 四套的 `*_ultra_heavy_chestplate.png` 换了新图，
  细节比之前丰富（尤其合金那套的花纹）。

- **超重型甲的自定义模型。** 作者用 Blockbench 给这套甲加了原版没有的装饰方块，
  之前直接用原版 `HumanoidModel` 渲染，那些方块根本不显示、贴图上为它们预留的
  UV 区域也落空。现在按四套各自的 UV 建了 8 个模型层（每套内外各一个）：

  | 部位 | 说明 |
  | --- | --- |
  | **肩甲 ×2** | 挂在左右手臂上，3×5×5，膨胀后 5×7×7 |
  | **膝盖护板 ×2** | 挂在左右腿上，6×4×1，膨胀后 7×5×2 |

  四套的 bbmodel 是分别画的，UV 位置各不相同，所以不能共用一份 `LayerDefinition`：

  | 套装 | 左肩 | 右肩 | 右腿护板 | 左腿护板 |
  | --- | --- | --- | --- | --- |
  | 金制 | (33, 0) | (48, 6) | (43, 22) | (43, 22) |
  | 铁制 | (33, 0) | (48, 6) | (43, 22) | **(43, 17)** |
  | 钻石 | (33, 0) | (48, 6) | (43, 22) | (43, 22) |
  | 合金 | (33, 0) | **(48, 0)** | (43, 22) | (43, 22) |

- **超重型甲的重量惩罚。** 按材质每件降低移动速度：

  | 套装 | 每件 | 穿满四件 |
  | --- | --- | --- |
  | 金制超重型甲 | 7.5% | 30% |
  | 铁制超重型甲 | 5% | 20% |
  | 钻石超重型甲 | 2.5% | 10% |
  | 合金超重型甲 | 10% | 40% |

  用 `AttributeModifier.Operation.ADD_MULTIPLIED_BASE`，按**基础**移动速度扣减：
  多个来源自动累加，且不会把迅捷药水、灵魂疾行之类的加成一起缩小。
  只作用于超重型甲，上一版的四种重型甲不受影响。

### 修复

- **头盔外面那层壳。** 原版 `HumanoidModel` 除了 `head` 还有一个 `hat`
  （比 head 大 0.5），而 `HumanoidArmorLayer` 渲染头盔时会连它一起打开：

  ```java
  p_117126_.setAllVisible(false);
  switch (slot) {
      case HEAD -> {
          p_117126_.head.visible = true;
          p_117126_.hat.visible = true;   // 把我们的设置覆盖掉
      }
  }
  ```

  所以**没法靠 `part.visible = false` 隐藏**，只能在模型定义里把 `hat` 换成
  没有方块的 PartDefinition（名称保留，因为 `HumanoidModel` 的构造要读它）。

- **肩甲的左右 UV 张冠李戴。** 之前左右写反了，且四套共用一份 UV。
  由于合金的左右肩甲 UV 恰好都在 `y=0` 一带，反了也看不出，只有金 / 铁 / 钻石
  会串到贴图别处。现已按套分开。

- **膝盖护板浮空、厚度不足。** 原先照搬 bbmodel 的 `z = -3.5`，离腿前表面
  （`z = -2`）有 1.5 格，加上只有 1 格厚，看起来就是块悬空的薄板。
  改由模型膨胀提供厚度——护板本身 1 格，膨胀 0.5 后视觉上是 2 格，
  且**不会破坏 UV 布局**。（直接改厚度参数会让侧面只有 1 像素宽的图案被拉成
  2 格、相邻像素串进来。）

- **装饰方块不跟着膨胀。** `addBox` 必须逐块显式传 `CubeDeformation`，
  只给 `createMesh` 传是不够的——原版 `createMesh` 里也是逐块传的。
  漏传会让肩甲比手臂小一圈。

## 安装

1. 安装 Minecraft 1.21.1 的 **NeoForge**（21.1.244 或更高的 21.1.x）。
2. 将附件中的 `盔甲附加-1.3.2.jar` 放入 `.minecraft/mods/`。
3. **不需要任何前置模组。**
