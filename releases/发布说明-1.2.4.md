# 盔甲附加 (Armor Addon) 1.2.4

Minecraft **1.21.1** / **NeoForge** 模组。

## [1.2.4]

### 变更

- **修正套装名称用字**：「铁质 / 金质 / 木质」改为「铁制 / 金制 / 木制」。
  这里要表达的是「用某材料制造」，应当用「制」而不是「质」。共改动 12 个物品名：

  | 原名 | 现名 |
  | --- | --- |
  | 铁质内衬头盔 / 胸甲 / 护腿 / 靴子 | **铁制**内衬头盔 / 胸甲 / 护腿 / 靴子 |
  | 金质内衬头盔 / 胸甲 / 护腿 / 靴子 | **金制**内衬头盔 / 胸甲 / 护腿 / 靴子 |
  | 铁质重型头盔 / 胸甲 / 护腿 / 靴子 | **铁制**重型头盔 / 胸甲 / 护腿 / 靴子 |

- 顺带统一了一处不一致：README 里原写作「木质盔甲音效」，现与物品名一致改为「木制」。

### 说明

- **注册 ID 全部未变**（仍为 `armor_addon:iron_lining_helmet` 等），
  因此已有存档、配方与其他模组的引用都不受影响，只是显示名变化。
- 「材质」是另一个词（指贴图），不在本次改动范围内。

## 安装

1. 安装 Minecraft 1.21.1 的 **NeoForge**（21.1.244 或更高的 21.1.x）。
2. 将附件中的 `盔甲附加-1.2.4.jar` 放入 `.minecraft/mods/`。
3. **不需要任何前置模组。**
