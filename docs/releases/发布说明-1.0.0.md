# 盔甲附加 (Armor Addon) 1.0.0

Minecraft **1.21.1** / **NeoForge** 模组。

首个公开版本。

### 新增

- **羊毛盔甲**（材料 `armor_addon:wool`）—— 4 件
  - 防御点同原版皮革（1 / 3 / 2 / 1），耐久为皮革的两倍，每件附带 2.0 护甲韧性。
  - 使用 `minecraft:wool` 标签修复，**任意颜色的羊毛**都可以。
  - 附魔亲和度同皮革（15）。
  - **羊毛靴子**另有两个特性：可在细雪上行走；移动时不会被幽匿感测体 / 坚守者探测到。

- **铁质内衬甲**（材料 `armor_addon:iron_lining`）—— 4 件
  - 由「对应铁盔甲 + 对应羊毛盔甲 + 锁链」在工作台合成。
  - 防御点比铁盔甲高 1（3 / 7 / 6 / 3），耐久为铁盔甲的 120%（198 / 288 / 270 / 234），韧性 2.0。
  - 合成时继承原铁盔甲的**附魔与自定义名称**，并按原盔甲已损耗的耐久同步初始损伤。

- **金质内衬甲**（材料 `armor_addon:gold_lining`）—— 4 件
  - 合成方式同上，用金盔甲。
  - 防御 3 / 6 / 4 / 2，耐久 92 / 134 / 126 / 109，韧性 2.0，附魔亲和度 25。

- **钻石内衬甲**（材料 `armor_addon:diamond_lining`）—— 4 件
  - 合成方式同上，用钻石盔甲。
  - 防御 4 / 9 / 7 / 4，耐久 435 / 633 / 594 / 514，韧性 **4.0**（钻石自身 2.0 + 羊毛 2.0）。

- **合金内衬甲**（材料 `armor_addon:alloy_lining`）—— 4 件
  - 工作台合成方式同上，用下界合金盔甲。
  - **额外提供锻造台升级路线**：钻石内衬甲 + 下界合金升级模板 + 下界合金锭。
  - 防御 4 / 9 / 7 / 4，耐久 488 / 710 / 666 / 577，韧性 **5.0**（下界合金 3.0 + 羊毛 2.0），
    击退抗性 0.1，且**抗火**（掉进岩浆不会烧毁）。

- 以上 5 套共 20 件盔甲，全部加入创造模式「战斗」物品栏。

### 说明

- 装备外观由 `textures/models/armor/<材质名>_layer_1.png` / `_layer_2.png` 提供。
- 内衬甲系列为单一固定材质，**不支持染色**。

## 安装

1. 安装 Minecraft 1.21.1 的 **NeoForge**（21.1.244 或更高的 21.1.x）。
2. 将下方附件中的 `盔甲附加-1.0.0.jar` 放入 `.minecraft/mods/`。
3. **不需要任何前置模组。**
