# 盔甲附加 (Armor Addon) 1.0.1

Minecraft **1.21.1** / **NeoForge** 模组。

### 变更

- **羊毛盔甲**：穿戴贴图 `wool_layer_1.png` / `wool_layer_2.png` 更换为手绘版本
  （64×32，38 / 37 色）。至此五套盔甲的穿戴贴图全部统一为同一手绘风格。

### 兼容性

- 未增删任何物品，注册 ID 与上一版完全一致，**旧存档可直接沿用**。

## 安装

1. 安装 Minecraft 1.21.1 的 **NeoForge**（21.1.244 或更高的 21.1.x）。
2. 将下方附件中的 `盔甲附加-1.0.1.jar` 放入 `.minecraft/mods/`。
3. **不需要任何前置模组。**
