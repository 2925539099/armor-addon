## 安装

1. 安装 Minecraft **1.21.1** 的 **NeoForge**（21.1.244 或更高的 21.1.x）。
2. 把对应版本的 jar 放进 `.minecraft/mods/`。
3. 启动游戏即可，**不需要任何前置模组**。

## 选哪个版本？

- **新装玩家**：直接用最新的 **1.3.4**。
- **已在用 1.1.0 的存档**：升到 1.2.0 只**新增**了锻造模板和四套重型甲，原有物品的
  注册 ID 全部没变，存档可以直接沿用。
- **已在用更早版本**：一路升上来即可，每次都只是新增内容，从未删改过任何已有物品。
- **回退旧版**：1.0.0 与 1.0.1 只差羊毛盔甲的穿戴贴图，功能完全相同。
- **注意 1.3.4 的配方变动**：合金超重型甲移除了锻造台捷径，只保留工作台路线。
  **这只影响新合成，已合成出来的物品不受影响**，存档安全。
